## Part 1: fixes (local)
- **Sudoku**: `load()` checks the whole save (`okGame`: level, 81 givens/values/notes/fix in range, a valid solution that matches the givens); damaged → fresh puzzle. Records and best times cleaned (`clean`). Last 60 undo steps saved (`hist`) and checked on load. Message line under the board (title, header, board, message, buttons, pad).
- **Sound / Scanlines**: kept on the cover (`naShared`, `naShare`); `naSet` in each game applies them. Never saved. A game that isn't on screen makes no sound.
- **Remi**: `leave()` (also `window.naLeave`, called by the cover's `showCover()`) resets Medias/Landscape on any exit incl. Back. Landscape rack: over 18 tiles `#rack.wide` = two-row grid (`--per` = half the hand), slides sideways, keeps its place, scrolls a new tile into view; table stays 150 (3 rows) with 19, 28, 38 tiles. "Normal" for level and speed; New game is the last Settings row. `remi_set` accepts only known values; `remi_rec` cleaned; `okSave` needs number scores, a whole round number and plain round results (they are written into the page).
- **Records**: `cleanRec` in Knucklebones and Othello, unknown saved difficulty → Normal; Water Sort `okN` (level 1–99,999, best/solved 0–99,999); Othello's saved undo `floor` checked (a damaged one made Undo throw; found by the improved fuzz).
- **Template**: every `max-width:360px` and `max-height` media rule removed. Settings buttons 64px on every screen (Medias Portrait 76px). Same touch behaviour in every game and on the cover (`touch-action:manipulation`, no text selection / long-press menu / tap flash). Hover glow (`filter:brightness`) for `(hover:hover) and (pointer:fine)`.
- **Othello**: label "Allow undo".

## Part 2: code clean-up (local)
- **Shared core**, put into each game by `games/build.py`:
  - `games/core.css`: palette, page, the 390 × 797 template (both the 1-player and flipped forms), title, bottom bar with Exit, Rules/Settings panel, rows, switches, action buttons, touch, hover, reduced motion.
  - `games/stage.js`: the scaling/turning script (was a Python string in build.py); it now also sets `html.rot` so scanlines follow a sideways picture in every game.
  - `games/core.js`: `audio`/`tone`/`sfx`, sound unlock (audio session + silent loop, now for all five; a game that got Sound from another game unlocks at its first tap; `naPause` when the cover takes over), `showPanel`, `setSw`, panel placing, outside tap / Escape, `naFirstRules`, Sound/Scanlines switches and sharing, Exit, "Tap again" (`naArm`, `naDisarm`).
  - A game sets `naSfx` (its sounds) and `naSync` (refresh of its Settings rows) and keeps only its own play area, rules and saved data. Each file ends with a short "differs from the shared core" block.
- **Old layouts removed**: each game's own rotate/short-screen code, `.rot`/`.rotated`/`.short`/`.tiny`/`.narrow` rules, env() paddings, the stage's `!important` overrides, the class watcher, build.py's per-game patches (Exit button, grid bar, panel script, Remi banner height) — the Exit button is now in each game's markup. Game files no longer work when opened on their own (accepted).
- **Sizes**: the five game files 219 KB → 171 KB, plus 13 KB of core; the page 345 KB → 342 KB (the core is packed into each game's frame).
- **Builds are repeatable** (font timestamp fixed): two builds give the same bytes.
- **Automatic tests**: `.github/workflows/checks.yml` runs on every pull request: `build_check` (index.html is a fresh build), `layout_compare origin/main`, `exit_check`, `core_check`, `resume_check`, `install_check`; these end with exit code 1 on failure (`harness.strict()`). Deploy routine is now: push, open the PR, wait for `checks` to pass, merge. **Note**: pushing a workflow file may need a permission the Claude GitHub connection lacks; if the push is refused, the user adds `.github/workflows/checks.yml` on GitHub by hand.
- **New tests**: `style_snapshot.py` (before/after: every element's position and styles on 41 screens × 6 sizes; fixed random numbers), `core_check.py` (shared behaviour in every game), `build_check.py`, `device_sweep.py` (36 sizes); `save_fuzz.py` closes open games first and reads the Settings text.
- **Proof the clean-up changed nothing visible**: snapshot before vs after, 41 screens × 6 sizes: no element moved or resized. Only differences: settings switches clip overflow and have 2px side padding in all games; labels never wrap in Othello/Sudoku Settings (none overflows); dead bar properties; and one intended fix: **scanlines now run the right way in Othello and Sudoku on a sideways phone** (they ran across the picture before).
- Small: Remi's `clearTimeout(T)` no-op removed. Left alone: the unused Google Fonts code in sw.js (no sw.js change, so no CACHE bump), the `window.__remi` test hook (tests use it).
- Possible later: pack the core once on the cover and let games copy it (like the fonts) to shrink the page by about 50 KB.
